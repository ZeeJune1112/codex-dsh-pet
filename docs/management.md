# Local pet management

Build with `npm run build`, then start the native Windows host with `npm run start:host`. Its console prints a private management URL. When Hooks launched the host without a console, run `npm run management:url` from this checkout to retrieve the running host's URL. Open it in a browser on this computer. The URL contains an access token; keep it local. The host never opens a browser for a Hook event and the Hook wrapper stays silent.

The manager listens on a random `127.0.0.1` port. Its HTML, standalone React bundle, previews, and APIs all require the random token. Mutations also require the exact local Origin and Host. Responses disable caching and referrers. The discovery file is `%LOCALAPPDATA%\codex-dsh-pet\management.json` and is removed on graceful shutdown. A restart creates a new port and token.

The page reuses the upstream pet card, styling, preview, ZIP/Petdex imports, scale, visibility and ordering controls. Each tile is a **pet instance**. Select its artwork with **Role**; **New instance of this role** creates another independent instance. Bind, unbind or rebind only the selected instance with a Codex session ID. Focus changes never rebind a pet. A new unbound instance is idle. A bound instance with no observed event shows **Unknown / No event observed**; silence does not establish whether Codex has approved Hooks. Stale permission waits remain possible waits.

A saved role that cannot load does not prevent other instances or management from starting. Its tile reports the load failure and retains its binding and settings; choose an available **Role** to recreate its window. Role updates wait for the instance's first window opening so saved artwork and the displayed window stay consistent.

Window and animation controls expose always-on-top, click-through, animation enable/speed, idle variation frequency and initial unbound sleep. After 60 seconds of unbound idle or an observed session end, the pet sleeps; **Hide while sleeping** then hides it. Observed activity wakes it. Unknown or waiting chats do not become idle merely because time passed. **Quit desktop pet host** closes every window and both local listeners; the next authorized Hook may start the host again.

All imports, catalog scans, previews, window atlases and settings use the same downstream directory. Imports create a selected, visible, unbound instance and validate the sprite before publishing its complete role directory. Imported assets remain local and are not included in the package or repository. Petdex downloads use HTTPS allowlisted asset URLs, reject redirects and enforce streamed size limits.

When the known upstream `~/.dsh/dsh-pet` directory contains state or roles, the page offers an explicit migration. **Not now** changes only the current server's memory. **Confirm migration** copies validated local manifests and sprites plus compatible role selection/order/visibility/scale/hide/position preferences. Existing downstream roles, instances and chat bindings win. No Codex chats or Hook approvals are inferred or copied. No old assets are loaded by the host before this operation.

Legacy preferences are imported into separate unbound instances, including roles already present downstream. Existing artwork is reused and existing instances are unchanged; the migration completion marker prevents duplicate imports on a second confirmation.

Migration rejects observed links/junctions, escaping paths, special files, invalid settings and invalid sprites. It stages on the downstream volume, publishes whole role directories, then saves state atomically. Handled failures remove only this operation's new directories and retain previous settings and source files. A process crash between directory publication and the state save can leave a complete orphan role; migration does not claim a crash-atomic multi-file transaction. Source path checks reject observed links but do not claim protection against a hostile process concurrently replacing source files.

Run `npm run verify:management` after building for a native-free smoke check of the emitted bundle, authenticated HTTP service, URL discovery, independent same-role instances and Quit. `npm test` additionally exercises the real HTTP adapter and React controls, imports, binding, sleep/wake and migration failure/decline/repeat behavior. For actual Windows rendering, `npm run start:host` uses the native backend. Physical multi-monitor/DPI/drag acceptance and actual reviewed Codex Hook delivery belong to ticket #7.
